# Courts Data Lab plugins for Claude

This repository is a Claude plugin marketplace from Professeer. It holds one plugin, [`courts-data-lab`](plugins/courts-data-lab), which connects Claude to Courts Data Lab: read-only case data from Indian courts, with hearing histories and links to court orders.

```
claude plugin marketplace add professeer/courts-data-lab-plugin
claude plugin install courts-data-lab@courts-data-lab
```

See the [plugin README](plugins/courts-data-lab/README.md) for what you need and how to use it. Documentation: https://api-docs.courtsdaily.info
